# Server Exports

RoadPhone Pro provides several server-side exports that allow other resources to interact with the phone system.

<Note>
  Running the SIM Card DLC? Issuing numbers, moving SIMs between phone and inventory and charging prepaid credits have their own reference: [SIM Card Exports](/roadphonepro/api/simcards).
</Note>

## Player Information

### getPlayerFromPhone

Get a player's server ID from their phone number.

```lua
local playerId = exports['roadphone']:getPlayerFromPhone(number)
```

<ParamField path="number" type="string" required>
  The phone number to look up.
</ParamField>

<ResponseField name="returns" type="number | nil">
  The player's server ID (source), or `nil` if not found or offline.
</ResponseField>

<CodeGroup>
```lua Example
local source = exports['roadphone']:getPlayerFromPhone("1234567")
if source then
    print("Player found with source: " .. source)
else
    print("Player not found or offline")
end
```
</CodeGroup>

---

### getNumberFromIdentifier

Get a player's phone number from their identifier.

```lua

```

<ParamField path="identifier" type="string" required>
  The player's identifier (license, citizenid, etc.).
</ParamField>

<ResponseField name="returns" type="string | nil">
  The player's phone number, or `nil` if not found.
</ResponseField>

<CodeGroup>
```lua Example

    print("Phone number: " .. phoneNumber)
end
```
</CodeGroup>

### getSourceFromPhone

Server ID of the player who owns a phone number. Prefer this over `getPlayerFromPhone` across resource boundaries — a framework player object loses its methods when it is serialised out of RoadPhone.

```lua
local src = exports['roadphone']:getSourceFromPhone(number)
```

<ParamField path="number" type="string" required>
  The phone number to resolve.
</ParamField>

<ResponseField name="returns" type="number | nil">
  The player's server ID, or `nil` when nobody online carries that number.
</ResponseField>

<Note>
  `GetPlayerSourceByPhoneNumber(number)` does exactly the same and is kept for existing integrations.
</Note>

<ResponseField name="returns" type="string | nil">

## Notifications

### PhoneNotifyPlayer

Push a phone notification to a player.

```lua
exports['roadphone']:PhoneNotifyPlayer(source, opts)
```

<ParamField path="source" type="number" required>
  The player's server ID.
</ParamField>

<ParamField path="opts" type="table" required>
  <Expandable title="properties">
    <ParamField path="apptitle" type="string">
      App name above the notification — locale key or raw text.
    </ParamField>
    <ParamField path="title" type="string">
      Notification headline.
    </ParamField>
    <ParamField path="message" type="string">
      Body text.
    </ParamField>
    <ParamField path="img" type="string">
      App icon URL.
    </ParamField>
    <ParamField path="app" type="string">
      Router name of the app to open when the notification is tapped.
    </ParamField>
    <ParamField path="path" type="string">
      Route path to open on tap — takes precedence over `app`.
    </ParamField>
    <ParamField path="banner" type="boolean">
      `false` skips the banner and only files it in the notification list.
    </ParamField>
    <ParamField path="lockscreen" type="boolean">
      `false` keeps it off the lockscreen.
    </ParamField>
  </Expandable>
</ParamField>

### PhoneNotifyNumber

Push a notification to a **phone number** instead of a player. This is the one you want in metadata mode: a player can carry several phones, and a notification belongs to one of them.

```lua
exports['roadphone']:PhoneNotifyNumber(phoneNumber, opts)
```

<ParamField path="phoneNumber" type="string" required>
  The recipient's phone number.
</ParamField>

<ParamField path="opts" type="table" required>
  Same fields as `PhoneNotifyPlayer`.
</ParamField>

<Note>
  Delivered live only while that phone is the one in hand. Otherwise it is queued under its number and surfaces the next time **that** phone is opened — offline recipients included.
</Note>

<CodeGroup>
```lua Example
exports['roadphone']:PhoneNotifyNumber('4821337', {
    apptitle = 'Bank',
    title    = 'Payment received',
    message  = 'You received $2,500 from Vangelico.',
    img      = '/public/img/Apps/light_mode/bank.webp',
    app      = 'bank_app',
})
```
</CodeGroup>

## Number Providers

Numbers that belong to no phone can be served by another resource: a phone box, a Trap Phone, a hotline. The core asks every registered provider in turn, and the first one that claims the number owns the call or message.

<Steps>
  <Step title="Register on startup">
    ```lua
    exports['roadphone']:registerNumberProvider(GetCurrentResourceName())
    ```

    <ResponseField name="returns" type="boolean">
      `true` once the resource is registered — calling it twice is harmless.
    </ResponseField>
  </Step>
  <Step title="Export the contract">
    Every function is optional; a missing one simply means "not my number".

    | Export | Signature | Returns | Description |
    |---|---|---|---|
    | `ExternalNumber_TryCall` | `fromNumber, toNumber, callerSource` | `boolean` | Take the call. `true` = handled. |
    | `ExternalNumber_TryMessage` | `fromNumber, toNumber, body` | `boolean` | Take the message. |
    | `ExternalNumber_IsReserved` | `number` | `boolean` | Does this number fall inside your range? |
    | `ExternalNumber_ResolveSource` | `number` | `source \| nil` | Who is currently reachable on it. |
    | `ExternalNumber_CallEvent` | `kind, info` | — | Call lifecycle events (`accept`, `decline`, `end`). |
  </Step>
</Steps>

<Warning>
  `ExternalNumber_IsReserved` is what stops the phone — and every SIM card — from ever issuing a number inside your range. Reserve exactly what you own: a provider that claims too much makes number generation fail for everyone.
</Warning>

<CodeGroup>
```lua Minimal provider
CreateThread(function()
    exports['roadphone']:registerNumberProvider(GetCurrentResourceName())
end)

local PREFIX = '555'

exports('ExternalNumber_IsReserved', function(number)
    return tostring(number):sub(1, #PREFIX) == PREFIX
end)

exports('ExternalNumber_TryCall', function(fromNumber, toNumber, callerSource)
    if tostring(toNumber):sub(1, #PREFIX) ~= PREFIX then return false end

    local channel = exports['roadphone']:generateCallChannelID()
    -- connect the caller with your NPC/hotline logic here
    return true
end)

exports('ExternalNumber_TryMessage', function(fromNumber, toNumber, body)
    if tostring(toNumber):sub(1, #PREFIX) ~= PREFIX then return false end
    print(('hotline SMS from %s: %s'):format(fromNumber, body))
    return true
end)
```
</CodeGroup>

## Dispatches

### sendDispatch

Send a dispatch notification to all members of a specific job.

```lua
exports['roadphone']:sendDispatch(source, message, job, coords, image)
```

<ParamField path="source" type="number" required>
  The source player ID sending the dispatch.
</ParamField>

<ParamField path="message" type="string" required>
  The dispatch message content.
</ParamField>

<ParamField path="job" type="string" required>
  The target job name (e.g., "police", "ambulance").
</ParamField>

<ParamField path="coords" type="vector3 | table">
  Optional coordinates for the dispatch location.
</ParamField>

<ParamField path="image" type="string">
  Optional image URL for the dispatch.
</ParamField>

<ParamField path="deathcause" type="string">
  Optional cause of death, shown by dispatch systems that display one.
</ParamField>

<CodeGroup>
```lua Example
-- Basic dispatch
exports['roadphone']:sendDispatch(source, "10-71 Shots Fired", "police")

-- With coordinates
local playerCoords = GetEntityCoords(GetPlayerPed(source))
exports['roadphone']:sendDispatch(source, "Medical Emergency", "ambulance", playerCoords)

-- With image
exports['roadphone']:sendDispatch(source, "Robbery in Progress", "police", coords, "https://example.com/robbery.jpg")
```
</CodeGroup>

<ParamField path="image" type="string">

</ParamField>

## Map Pins

Pins that a resource owns: they show up in the phone's Maps app, optionally with a world blip and a route. The same API exists [client-side](/roadphonepro/api/client#map-pins).

### AddMapPinForPlayer

```lua
local id = exports['roadphone']:AddMapPinForPlayer(source, data)
```

<ParamField path="source" type="number" required>
  The player who should see the pin.
</ParamField>

<ParamField path="data" type="table" required>
  <Expandable title="properties">
    <ParamField path="x" type="number" required>
      World X coordinate.
    </ParamField>
    <ParamField path="y" type="number" required>
      World Y coordinate.
    </ParamField>
    <ParamField path="z" type="number">
      World Z coordinate.
    </ParamField>
    <ParamField path="label" type="string">
      Text shown on the pin.
    </ParamField>
    <ParamField path="icon" type="string">
      Emoji or icon name for the pin marker.
    </ParamField>
    <ParamField path="color" type="string">
      Hex colour, e.g. `'#FF3B30'`.
    </ParamField>
    <ParamField path="route" type="boolean">
      `true` also sets a GPS route to the pin.
    </ParamField>
    <ParamField path="blip" type="table">
      `{ sprite = number, color = number }` for an additional world blip.
    </ParamField>
    <ParamField path="id" type="string">

    </ParamField>
  </Expandable>
</ParamField>

<ResponseField name="returns" type="string | nil">

</ResponseField>

## RoadDrop (AirDrop)

### sendRoadDrop

Send a photo, a contact card or a playlist to one player's phone, exactly like an in-game RoadDrop share.

```lua
exports['roadphone']:sendRoadDrop(data)
```

<ParamField path="data" type="table" required>
  <Expandable title="properties">
    <ParamField path="playerId" type="number" required>
      Server ID of the **receiving** player.
    </ParamField>
    <ParamField path="picturelink" type="string">
      Image URL to share. Lands in the receiver's Photos app.
    </ParamField>
    <ParamField path="contact" type="table">
      Contact card: `{ firstname, lastname, number, picture }`.
    </ParamField>
    <ParamField path="playlist" type="table">
      A playlist object to share with the Music app.
    </ParamField>
    <ParamField path="roadpad" type="boolean">
      `true` delivers a shared picture to RoadPad instead of the phone.
    </ParamField>
  </Expandable>
</ParamField>

<Note>
  Exactly one content field is used per call — `picturelink`, `contact` or `playlist`, in that order of precedence. Without any of them nothing is delivered and the sender is notified.
</Note>

<Warning>
  The sender's name is resolved from the **current server event context**, not from an argument. Call this from inside a player-triggered event handler (or a command), otherwise there is no sender to resolve and the share is rejected.
</Warning>

<CodeGroup>
```lua Share a photo
RegisterServerEvent('mycam:sharePhoto')
AddEventHandler('mycam:sharePhoto', function(targetId, url)
    exports['roadphone']:sendRoadDrop({
        playerId    = targetId,
        picturelink = url,
    })
end)
```

```lua Share a contact card
exports['roadphone']:sendRoadDrop({
    playerId = targetId,
    contact  = {
        firstname = 'Marie',
        lastname  = 'Delacroix',
        number    = '4821337',
        picture   = '/public/img/user.png',
    },
})
```
</CodeGroup>

<Note>
  **Deprecated alias:** `sendAirdrop(data)` behaves identically. Use `sendRoadDrop` in new code.
</Note>

### Crypto Payment System

```lua
-- Accept cryptocurrency payments
function AcceptCryptoPayment(identifier, coinId, amount)
    -- Check if player has enough
    if exports['roadphone']:checkcryptoamount(identifier, coinId, amount) then
        -- Remove crypto from player
        exports['roadphone']:removecrypto(identifier, coinId, amount)

        -- Send confirmation email
        exports['roadphone']:sendMailOffline(identifier, {
            senderMail = "crypto@exchange.com",
            subject = "Payment Confirmed",
            message = string.format("Your payment of %.4f has been processed.", amount)
        })

        return true
    end
    return false
end
```
