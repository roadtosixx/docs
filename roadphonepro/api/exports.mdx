RoadPhone Fold is included with RoadPhone Pro and uses the same `roadphone` resource. This index covers the current 2.7.0 manifest and runtime registrations. Export names are case-sensitive; names shared by client and server can have different parameters.

Call exports from the side shown after RoadPhone has started. Follow each reference for arguments, return values and configuration requirements. Addon exports require their addon to be loaded; listing an addon here does not imply that separate addon is included in Pro.

```lua
dependency 'roadphone'
```

There are **no Fold-specific exports** in this build. See the command and saved settings in [Fold integration](/roadphonepro/fold#integration-and-exports). Global Lua functions are not automatically exports.

## Compatibility names

Account-blob metadata exports remain for compatibility; they do not create or clear current sessions. See [legacy account exports](/roadphonepro/api/metadata#accounts-legacy). The older `sendAirdrop` name aliases `sendRoadDrop`; prefer the current name. RoadBuds retains the `usingRoadPods` export.
