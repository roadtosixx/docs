### Save reports success but the files are unchanged

On Linux the FXServer process often runs as a different user than the one that uploaded the resource, leaving it without write permission on the config files. See [Admin Menu File Permissions](/roadphonepro/admin-menu-file-permissions) for the diagnosis and the `chown` fix.
